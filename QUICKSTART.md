# 🚀 VoiceCA - Quick Start

## **To Run the App (Windows)**

### Option 1: Automatic (Easiest)
```bash
Double-click: start-app.bat
```
This will automatically start both backend and frontend.

### Option 2: Manual (Terminal)

**Terminal 1 - Backend:**
```bash
cd backend
npm start
```
Backend will run on `http://localhost:3001`

**Terminal 2 - Frontend:**
```bash
cd frontend
npm run preview
```
Frontend will run on `http://localhost:4173`

---

## **To Test the App**

1. Open: `http://localhost:4173`
2. Click "Try Demo" → Instant access (no signup)
3. Click "📝 Form" or "⚡ Quick" to add entry
4. Fill details or select template
5. Click "Add" → Get tax calculations instantly
6. Change language → See UI in हिंदी/ગુજરાતી/मराठी

## **Important: Always Start Backend First**

If you get "Unexpected token '<'" error:
1. The backend isn't running
2. Start it with `npm start` in backend folder
3. Wait 3 seconds for it to initialize
4. Then use the frontend
